## 🚀 Quick Deploy Options (Choose ONE)

### Option 1: GitHub Pages (RECOMMENDED - Easiest!)

1. **Create a GitHub account** (if you don't have one): https://github.com/join

2. **Create a new repository**:
   - Go to https://github.com/new
   - Repository name: `adamcornelis.github.io` (this will be your URL!)
   - Make it Public
   - Click "Create repository"

3. **Upload your files**:
   - Click "uploading an existing file"
   - Drag ALL files from your portfolio folder
   - Scroll down and click "Commit changes"

4. **Enable GitHub Pages**:
   - Go to repository Settings → Pages
   - Under "Source", select "main" branch
   - Click Save

5. **Done!** Your site will be live at: `https://adamcornelis.github.io`
   (May take 2-3 minutes to go live)

### Option 2: Netlify Drop (Also Super Easy!)

1. Go to https://app.netlify.com/drop
2. Drag your entire portfolio folder onto the page
3. Done! You'll get a free URL like `https://random-name-123.netlify.app`
4. You can change the URL in site settings

### Option 3: Vercel (Fast & Professional)

1. Go to https://vercel.com/new
2. Sign up with GitHub
3. Click "Import Project"
4. Upload your portfolio folder
5. Click Deploy
6. Your site is live!

## ✏️ Need to Make Changes?

### If using GitHub Pages:
1. Go to your repository
2. Click on the file you want to edit
3. Click the pencil icon
4. Make changes
5. Scroll down and click "Commit changes"
6. Changes will appear on your site in ~1 minute

### If using Netlify/Vercel:
1. Make changes to the files on your computer
2. Drag the updated folder to Netlify Drop again (it will update)
   OR re-deploy on Vercel
